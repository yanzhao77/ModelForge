# 控制面验证证据登记册（CP6）

**状态：** 空白登记册；尚未授权验证。  
**候选提交（40 位 SHA）：** 待固定。  
**适用范围：** CP1–CP8 的未来最小化行为验证与发行评审。  
**禁止解释：** 本文档、其中的模板字段和静态审阅记录均不是测试、验收、审计或发行通过证据。

## 1. 启用前置条件

登记册只能在以下条件全部满足后启用填写：工作区已审阅并提交；唯一完整的 40 位候选 SHA 已固定；授权记录明确允许动作、隔离环境、用户范围、时间窗和资源上限；所有对象、日志、截图及导出均已按最小化脱敏规则准备。

| 前置项 | 允许的登记值 | 当前值 | 未满足时的处理 |
|---|---|---|---|
| `candidate_sha` | 单一、完整 40 位 Git SHA。 | 待固定。 | 不得填写运行性证据。 |
| `baseline_sha` | 候选前的已同步基线 40 位 SHA。 | 待固定。 | 不得比较或声称回归结论。 |
| `authorization_record` | 授权编号或受控引用，不含个人资料/凭据。 | 未提供。 | 不得启动任何验证。 |
| `environment_summary` | 隔离环境、版本和资源约束的无敏感摘要。 | 未收集。 | 不得连接真实对象。 |
| `redaction_review` | 脱敏审阅状态与责任人角色。 | 未完成。 | 不得保存截图、响应或日志。 |

## 2. 禁止收集字段

任何证据记录、截图、响应摘录、审计头字段、日志摘要或导出物不得包含下列字段或其等价信息。

| 禁止类别 | 示例 | 允许替代 |
|---|---|---|
| 凭据 | API key、token、密文、哈希、前缀、长度。 | `credential_present: true/false`。 |
| 正文 | prompt、输入、metadata 正文、模型输出、工具参数、Memory/文档内容。 | 数量、布尔值、稳定类别或不可逆摘要。 |
| 定位信息 | 本地路径、数据集路径、endpoint URL、设备用户目录。 | 资源类型、受控环境标识或配置状态。 |
| 所有权细节 | 其他用户 ID、用户名、对象名称、存在性差异。 | `unavailable` 响应类别和当前用户范围布尔值。 |
| 原始失败内容 | exception、traceback、HTTP 正文、日志行。 | 稳定错误码、HTTP 类别、可重试布尔值、关联标识。 |

## 3. 证据记录最小模式

每一行代表**一个已授权场景**，而不是一次任意请求。未运行时必须保持 `status: not_run`，不得填写“通过”或推断性结论。

| 字段 | 格式 | 敏感性要求 |
|---|---|---|
| `evidence_id` | `CPx-<area>-NN`。 | 不含用户、对象或时间信息。 |
| `candidate_sha` | 唯一 40 位 SHA。 | 必须与证据包其他行一致。 |
| `contract_ref` | CP 契约/目录中的动作或条目名称。 | 不含请求输入。 |
| `scenario_class` | `unconfirmed`、`confirmed_minimal`、`scope`、`conflict`、`expiry`、`ui`、`coordination` 或 `release_gate`。 | 不含目标名称。 |
| `status` | `not_run`、`blocked`、`passed`、`failed` 或 `no_go`。 | `passed/failed/no_go` 仅能在授权执行后填写。 |
| `result_code` | 稳定控制面错误码或受控结果类别。 | 不含异常正文。 |
| `correlation_id` | 可选受限关联标识。 | 不得替代用户/对象标识。 |
| `effect_summary` | 零/一最小对象计数和稳定状态类别。 | 不含对象详情、路径或正文。 |
| `audit_summary` | 动作、确认、用户范围布尔值、持久化类别。 | 仅允许白名单字段。 |
| `artifact_ref` | 经脱敏材料的受控引用。 | 不包含文件路径、URL 或内容。 |
| `reviewer_role` | 角色而非个人身份。 | 不含姓名或账号。 |

## 6. 填写与停止规则

先填写前置条件，再固定 SHA，之后按 CP1 至 CP8 交叉索引顺序进行经授权的最小化场景。每个场景都应先记录 No-Go 检查结果；一旦发现未确认副作用、跨用户可枚举、正文/凭据泄露、错误回执不诚实、预览执行、候选 SHA 漂移或未经授权运行，必须立即标记 `no_go` 并停止后续收集。
