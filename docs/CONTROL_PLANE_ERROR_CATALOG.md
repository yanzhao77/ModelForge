# 控制面稳定错误目录

**代码单一事实来源：** `backend/app/core/control_plane_errors.py`。本文件描述其使用规则；新增或调整稳定错误码时，应先更新代码目录，再同步本文档。

控制面错误响应必须使用稳定的 `code`、无正文的用户安全消息和 `correlation_id`。客户端根据 `code` 和关联标识进行当前语言提示，不得展示 HTTP 响应正文、异常字符串、堆栈、输入、模型输出、工具参数、路径或任何凭据。

| 错误类别 | 代表代码 | HTTP 状态 | 是否建议重试 | 必须具有关联标识 | 禁止暴露 |
|---|---|---:|---|---|---|
| 确认缺失 | `*_CONFIRMATION_REQUIRED`、`PLUGIN_CONFIRM_REQUIRED` | 409 | 否；应重新获得用户确认 | 是 | 确认细节、请求正文 |
| 审计字段拒绝 | `CONTROL_AUDIT_METADATA_REJECTED` | 500 | 否；应修正服务端策略 | 是 | metadata、数据库异常、堆栈、正文 |
| 审计持久化未知 | `*_AUDIT_DURABILITY_UNKNOWN` | 503 | 是；先只读核实状态 | 是 | 数据库异常、堆栈、正文、凭据 |
| 用户范围不可用 | `TASK_UNAVAILABLE`、`WORKSPACE_RESOURCE_UNAVAILABLE`、`MEMORY_UNAVAILABLE` | 404 | 否；不得推断对象存在性 | 是 | 所有权、跨用户存在性、正文 |
| 乐观并发冲突 | `TASK_VERSION_CONFLICT` | 409 | 是；刷新当前用户可见快照后再确认 | 是 | 当前状态细节、其他用户信息 |
| 预览策略无效 | `EXECUTION_INTENT_PREVIEW_ACTION_INVALID` | 400 | 否；应选择受支持的只读预览动作 | 是 | 目标 ID 列表、metadata、异常 |

> **兼容性约束：** 目录是渐进迁移的约束，不会自动重写尚未迁移的历史端点。每个迁移端点仍需保留其已承诺的兼容字段，并且不得将目录当作执行、授权或异常详情输出机制。

## 维护要求

每个新条目应固定 HTTP 状态、可重试语义、关联标识要求和禁止字段。错误码文本不得包含用户输入、对象名称、文件路径、连接地址、token、API key、模型响应或原始异常。任何展示或验证均需遵守独立授权与固定 SHA 证据要求，当前目录本身不构成行为验证或发行批准。
