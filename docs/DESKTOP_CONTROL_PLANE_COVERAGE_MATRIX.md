# 桌面控制面覆盖矩阵（CP5）

本矩阵将桌面页面与 CP1–CP4 的控制面契约交叉关联。检查范围为静态代码和本地化资源；不启动 PySide6、SSE 或 API 请求，不模拟确认或运行性动作。

| 页面/组件 | 高风险或受控入口 | 用户确认 | 请求键/协作关闭 | 安全错误与关联标识 | 静态状态 |
|---|---|---|---|---|---|
| `agent_page.py` | 创建和取消 Agent Run。 | 已在创建/取消前弹出确认，仅确认后传递 `confirm=true`。 | 使用 `AsyncApiMixin` 请求键与关闭回收。 | 使用本地化稳定错误格式化。 | 已覆盖。 |
| `task_center.py` + `task_store.py` | 单项/批量重试、取消和 SSE 快照。 | 已有确认框；确认后才传递 `confirm=true` 与当前可见版本。 | Store 采用协作中断、有限等待和 SSE 重同步。 | 使用稳定错误码/关联标识；批量结果不显示任务正文。 | 已覆盖。 |
| `training_page.py` | 开始、停止训练与模型注册。 | 三项动作均在确认后才传递 `confirm=true`。 | 使用共享异步请求键和关闭回收。 | 使用三语言提示与稳定错误格式化。 | 已覆盖。 |
| `control_center_page.py` | Memory、产物、集合关联/删除、配置档删除及只读诊断。 | 删除/关联操作已有确认；只读诊断不请求确认。 | 使用 `AsyncApiMixin` 和请求键。 | 异步失败使用稳定错误格式化；部分既有确认正文仍待渐进本地化。 | 主要覆盖。 |
| `run_timeline.py` | Run 审批与时间线流。 | 审批遵循确认契约。 | 已移除强制终止，采用 `requestInterruption()` 和有限等待。 | 流/审批失败使用稳定错误格式化。 | 已覆盖。 |
| `provider_dialog.py` | provider 保存、验证、删除。 | 验证有显式确认；保存为配置写入，删除有显式确认。 | 继承 `AsyncApiMixin` 并在关闭时回收。 | 验证失败使用 code/关联标识；密钥为密码字段且不回显。 | 主要覆盖。 |
| `automation_page.py` | 计划启停、立即运行、删除、预览与历史读取。 | 启停、立即运行、删除均在确认后传递 `confirm=true`；预览/历史为读取路径。 | 使用请求键并在关闭时协作回收。 | 失败使用稳定错误格式化；历史视图不展示服务端错误正文；确认文案已三语言化。 | 已覆盖。 |
| `chat_page.py` | 本地 runtime 启动、会话读取和消息请求。 | 非 Agent/任务控制面，但属于模型运行入口。 | 使用 `AsyncApiMixin`，关闭采用协作中断。 | 会话读取与模型加载仍有直接异常文本展示，CP5 将改为稳定格式化。 | 待静态修复。 |
| `execution_intent_preview.py` | 只读预览摘要。 | 不提供执行确认，`can_execute` 恒为 `False`。 | 纯展示模型，无后台 worker。 | 不保留 token、目标标识或摘要；使用三语言只读文案。 | 已覆盖。 |

## 覆盖准则

高风险操作必须具有显式用户确认、调用侧 `confirm=true` 传递、稳定错误码与关联标识展示，以及页面关闭时的协作取消或失效回调。页面不得因预览、刷新、诊断或加载而自动触发 Agent Run、任务重试/取消、训练、provider 验证、插件/MCP 生命周期或计划运行。

动态 UI 不得显示原始异常、token、API key、路径、请求正文、模型输出、工具参数或未脱敏日志。每个新增页面应在首次合并前加入本矩阵，并通过纯静态检查确认不存在自动确认、`terminate()` 强杀或错误正文拼接。

> 本矩阵不等同于桌面功能验收。确认对话框、关闭线程、SSE 断线、三语言切换和 API 错误分支均须在固定候选 SHA、明确授权和隔离验证环境中运行验证。
