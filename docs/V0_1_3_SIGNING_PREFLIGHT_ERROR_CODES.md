# v0.1.3 签名预检错误码说明

签名预检仅允许报告环境变量**名称是否存在**。它不读取、回显或验证证书、私钥、令牌和密码；预检成功也不等于可以签名或发布。

| 错误码 | 含义 | 允许的下一步 | 禁止推论 |
|---|---|---|---|
| `SIGNING_ENV_MISSING` | 受保护签名环境缺少必需变量名。 | 由有权限的负责人在受保护环境中配置后重新预检。 | 不得在日志中请求或粘贴 Secret。 |
| `SIGNING_ENV_UNAVAILABLE` | 当前执行环境未连接受保护签名配置。 | 停止签名准备并记录阻断项。 | 不得使用本地占位值替代生产凭据。 |
| `SIGNING_ENV_NAME_INVALID` | 变量名或平台映射不符合配置契约。 | 更正文档或受保护环境配置。 | 不得猜测变量内容。 |
| `SIGNING_PREFLIGHT_ONLY` | 仅完成变量名结构检查。 | 继续等待签名授权与原生平台验证。 | 不得宣称证书、GPG 或时间戳可用。 |
