# 运行时可观测性与脱敏：验证及证据映射

**候选 SHA：** `TBD`。开始验证前必须替换为单一、完整的 40 位 Git SHA。
**当前结论：** **No-Go**。本文件只定义未来的验证证据，不能作为任何已通过测试、签名、发布或安全认证的依据。

## 1. 共通证据规则

所有未来证据必须仅保存命令、固定 SHA、环境摘要、日期、执行人、通过/失败状态、脱敏响应字段和必要的哈希。不得保存 API Key、Bearer token、cookie、密码、私钥、证书、模型输入/输出、工具参数、知识正文、完整异常、用户身份信息或原始事件 payload。

| 工作包 | 未来验证目标 | 最小脱敏证据 | No-Go 条件 |
|---|---|---|---|
| OR1：事件脱敏 | 含凭据键、输入/输出、工具参数、错误详情的事件在持久化与 SSE 前均被替换；序号保持递增。 | 字段名、`payload_redacted`、序号、事件类型和已脱敏断言。 | 出现原文、凭据形态、正文，或脱敏导致 event key/序号异常。 |
| OR2：只读诊断 | EventBus 队列/写失败/溢出和后台任务计数正确，诊断调用不触发 publish、flush、恢复或写入。 | 聚合 JSON、前后数据库计数、日志中无正文的异常类型。 | 诊断包含 payload/堆栈，或调用产生 DML、恢复、清理、任务执行。 |
| OR3：桌面呈现 | 三语言下只显示聚合数字、布尔值和稳定异常类型；关闭时协作取消正确。 | 三语言截图、请求键记录、关闭路径摘要。 | 混合静态语言、显示正文/堆栈，或自动触发运行时操作。 |
| OR4：OpenAI 兼容错误 | 非流式 500 与流式 SSE error 均包含稳定 code/关联标识，不回显底层异常，成功响应仍兼容。 | HTTP/SSE 字段白名单、响应头、脱敏错误断言。 | `str(exception)`、input/output、token 或协议破坏出现在错误响应。 |
| OR5：文档治理 | 实际候选 SHA、工作包范围、验证输出和 Go/No-Go 决策一致。 | manifest、清单哈希和审批记录。 | 使用分支名代替 SHA，或把 `not_run` 写为 `passed`。 |

## 2. 执行前后约束

验证必须得到用户的单独明确授权，并以单一候选 SHA 冻结范围。验证期间如果发现任何敏感字段或执行性副作用，应停止后续步骤，保留脱敏失败摘要并维持 No-Go。未完成的验证不得通过新增 tag、修改版本号、生成签名、上传构建资产或创建 GitHub Release 规避。
