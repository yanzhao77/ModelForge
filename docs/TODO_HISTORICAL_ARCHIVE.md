# ModelForge 历史待办归档索引

本文件将旧迭代中不再作为当前执行队列的事项从 `todo.md` 的“当前有效未完成工作”语境中分离。它保留版本、发行、安全和验证决策历史，**不表示这些事项已验证、已取消或不再需要**。

| 历史周期 | 保留事项 | 当前处理原则 |
|---|---|---|
| v0.1.1-beta.1 | Windows/Linux 原生安装 smoke、CPU/GPU Runner、真实推理 smoke、Pre-release 的跨平台补充证据。 | 需要外部环境、受控模型或用户授权时再单独恢复为验证任务。 |
| v0.1.2 | 真实使用反馈、跨平台签名、正式版本提升与发行门槛。 | 仍受版本号、签名、验证证据及人工审批约束。 |
| 早期功能机会 | 自动化、Agent 工作台、记忆/产物、插件/MCP、知识集合与模型洞察的原始规划。 | 已被后续实现计划取代；是否通过验证须以固定候选 SHA 的证据为准。 |
| 早期 Git 传输 | v0.1.2-dev/v0.1.3-dev 的临时网络或推送阻塞描述。 | 已由后续远端同步记录取代；不得据此移动标签或改写历史。 |

## 归档使用规则

需要恢复任何项目时，应把它复制到 `todo.md` 的“当前有效未完成工作”，并补充依赖、固定 SHA、授权状态和脱敏证据位置。不得将历史 CI、旧提交或已过时的网络故障描述作为当前候选的验证结论。
